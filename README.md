# 漫画コレクション管理アプリ

手持ちの漫画を管理する軽量Webアプリです。データはスマホ(ブラウザ)の中に直接保存されるので、Macを起動していなくても、Wi-Fiがなくても使えます。

- 何の漫画を何巻まで持っているか一覧で管理
- 抜けている巻（欠番）を自動検出
- 新刊が出たら通知（楽天ブックスAPIを利用、任意設定）
- スマホのブラウザから確認可能。ホーム画面に追加すればアプリのように単独で起動できる（PWA）
- データは端末内のIndexedDBに保存。サーバーやデータベースを別途用意する必要なし

## 構成（完全クライアント完結型）

- フロント: 素のHTML/CSS/JS（ESモジュール、フレームワーク不使用）
- データ保存: ブラウザのIndexedDB（`public/idb.js`, `public/store.js`）
- 新刊チェック: 楽天ブックス書籍検索APIをブラウザから直接呼び出し（CORS対応済みAPIのためサーバー不要）
- `src/server.js` は初回アクセス用の軽量な静的ファイル配信サーバー（API・DBは持たない）

一度スマホでアプリを開いてホーム画面に追加すれば、Service Workerがアプリ本体をキャッシュするため、以後はネットワークが無くてもアプリが起動し、これまで登録したデータもそのまま確認できます（新刊チェックのみインターネット接続が必要）。

## セットアップ・起動（ローカルで試す場合）

```bash
npm install
npm start
```

起動すると以下のように表示されます。

```
このPCから:   http://localhost:3000
スマホから:   http://<PCのIPアドレス>:3000  (同じWi-Fiに接続してください)
```

Wi-Fi経由でスマホから開き、共有メニューから「ホーム画面に追加」してください。以後はこのアイコンから単独で起動できます。

## 出先からも使えるようにするには

上記のローカルサーバーは初回ロード用です。iPhoneのService WorkerはHTTPS（またはlocalhost）でないと正しく登録されないため、`http://<LAN IP>:3000` のままだと、Wi-Fiの外に出た時にオフラインキャッシュが効かない場合があります。

外出先でも確実に使えるようにするには、`public/` フォルダを無料の静的ホスティング（GitHub Pages、Cloudflare Pages、Netlifyなど）にHTTPSで公開し、そのURLをスマホでホーム画面に追加するのがおすすめです。公開後はMacを起動しておく必要は一切なくなります。

## 新刊チェックの設定

アプリ右上の⚙️（設定）から、楽天ウェブサービスの無料アプリID（[取得はこちら](https://webservice.rakuten.co.jp/app/create)）を入力すると使えるようになります。入力したIDはその端末のブラウザ内にのみ保存されます。未設定でも所持巻管理・抜け巻検出は問題なく使えます。

各作品に設定した「検索キーワード」（未指定なら作品名）で楽天ブックスを検索し、タイトルから巻数を推定して、所持している最大巻より新しいものを「新刊」として表示します。作品によっては巻数の自動抽出がうまくいかない場合があるため、その際は検索キーワードを調整してください。

## データについて

すべてその端末（ブラウザ）のIndexedDB内に保存されます。ブラウザのサイトデータを消去すると失われるため、機種変更などの際は事前に伝えていただければエクスポート機能の追加も可能です。
